# Student Performance Predictor

A machine learning project that predicts a student's final score using study hours, attendance, and past scores.

## Tech Stack
- Python
- Pandas
- Scikit-learn
- Matplotlib

## Features
- Loads and cleans student data
- Trains a Linear Regression model
- Predicts final scores on test data
- Displays model accuracy (R² Score: 0.937)
- Visualizes actual vs predicted scores with a scatter plot
